Ctrl+Alt+D now toggles Designer's light/dark mode using its built-in temporary theme toggle.

Ctrl+Alt+0 collapses Design Elements, Properties, and Schematic Elements together. Press it again when all are collapsed to expand them. A mixed layout collapses first; closed and floating panels stay unchanged. The existing Ctrl+Alt+1/2/3 shortcuts still toggle individual sidebars.

Both actions are available in View and work with Schematic Tools closed. Shortcuts also remain available from Component Controls Info. Restart Designer after installing the update.
